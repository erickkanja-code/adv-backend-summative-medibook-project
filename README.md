# MediBook — clinic appointment booking backend

Express 5 · MySQL 8 · Redis · Jest. Work in progress: the full documentation is added at the end of the build.

## Setup

```bash
npm install
cp .env.example .env    # then edit the values
npm start               # http://localhost:3000/health
```

Requires Node.js 18+, MySQL 8.0.16+ and Redis 6.2+.
